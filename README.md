# APT Assistant v0.1

DCAT·LG Way Fit을 e-book 교재와 함께 연습하는 Windows용 웹 앱입니다. 영역별 타이머, OMR 답안, 계산기·메모·그림판을 한 창에서 쓰고, 풀이 뒤 정답을 입력하면 시간 내 점수와 전체 점수를 확인할 수 있습니다.

## 실행과 창 배치

프로젝트 폴더에서 아래 명령으로 바탕화면 바로가기를 만듭니다.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/make-shortcut.ps1
```

바탕화면 **APT Assistant**를 실행하세요. 바로가기는 Google Chrome으로 `app/index.html`을 엽니다. 첫 실행에서는 **Win+→**로 툴을 오른쪽에 붙이고, e-book을 왼쪽에 놓은 뒤 경계선을 끌어 **e-book:툴 ≈ 70:30**으로 맞추세요. 툴에 키보드 포커스를 두고 e-book 위에서 마우스 휠로 페이지를 넘깁니다.

## 한 세션, 6단계

1. 홈에서 **새 세션**을 누릅니다.
2. DCAT/LG 프로필과 **범위·모드**를 선택합니다. 전체 모의, 영역 하나, 자유 드릴 중 고르고 세트·문항 수 등을 맞춥니다.
3. **시작**을 누르고 준비 화면에서 **시작**을 눌러 타이머를 켭니다.
4. 영역별 OMR을 풀며 **답은 마우스로** 고릅니다. 숫자키는 계산기에 사용하고, 메모를 쓰다가 **Esc**를 누르면 키 입력이 계산기로 돌아갑니다. 영역이 끝나면 다음 영역으로 진행합니다.
5. 마지막 영역에서 **종료 → 확인** 후 **정답 숫자열을 붙여넣기**합니다. 예: `12345`. 미리보기와 입력 오류를 확인하고 **채점 저장**을 누릅니다.
6. **결과**에서 시간 내/전체 점수, 영역별 소요 시간과 미응답 등을 확인합니다. 정답이 아직 없으면 **나중에 채점**을 선택하고 홈의 채점 대기 목록에서 이어갈 수 있습니다.

## 모드와 시간 조정

| 선택 | 동작 |
| --- | --- |
| 실전 | 제한 시간이 되면 강제 마감합니다. 일시정지가 없고, 쉬는 시간이 끝나면 다음 영역이 자동 시작됩니다. |
| 연습 | 제한 시간을 넘겨도 계속 풀며 초과 시간을 기록합니다. 일시정지할 수 있습니다. |
| 외부 모의: 타이머·도구만 | 합격시대 같은 사이트에서 답을 고르고, 이 앱은 영역 타이머와 허용된 도구만 사용합니다. 종료 뒤 영역별 시간 요약을 확인합니다. |

**DCAT 공간추리·도형추리에서는 계산기·메모·그림판이 잠깁니다.** 외부 모의에서도 해당 영역의 도구 제한이 적용됩니다.

시작 화면의 **조정**에서 영역별 시간(`분:초`)과 **쉬는 시간(초)**을 바꾸고 **저장**하세요. **교재 기본값으로**를 누르면 기본 설정으로 돌아갑니다.

## 기록과 백업

세션이 끝난 뒤 채점 저장·나중에 채점·외부 모의 요약 확인을 마치면 JSON 백업이 자동 다운로드됩니다. 설정의 **세션 종료 시 자동 백업**을 켜 두고, 다운로드된 `apt-backup-날짜-시간.json`을 보관하세요. **지금 내보내기**로도 백업할 수 있습니다. 복원은 **설정 → 백업 파일 복원**에서 JSON을 선택하고 내용을 확인한 뒤 진행합니다.

앱 기록은 전용 Chrome 프로필 **`%LOCALAPPDATA%\APT-Assistant\chrome-profile`**에 저장됩니다. **이 폴더를 지우지 마세요.**

## 업데이트와 되돌리기

프로젝트 폴더에서 `npm run release`를 실행하면 검사·빌드 후 `dist/index.html`을 `app/index.html`로 복사합니다. 직전 빌드는 `app/prev/index.html`에 보관됩니다. 되돌리려면 앱 창을 닫고 **`app/prev/index.html`을 `app/index.html` 위에 복사**한 뒤 바로가기로 다시 실행하세요.

## 처음 한 번, 수동 확인 6가지

1. 70:30 스냅에서 OMR과 도구가 창에 잘 들어오는지 확인합니다.
2. 그림판의 펜 감각과 반응을 확인합니다.
3. 툴에 포커스를 둔 상태에서 휠로 e-book이 넘어가는지 확인합니다.
4. 바탕화면 바로가기가 앱 전용 창으로 열리는지 확인합니다.
5. 종료 알림 비프 음량을 확인하고 필요하면 설정의 **소리**를 조정합니다.
6. 백업을 두 번 연속 다운로드해 보고 Chrome이 연속 다운로드 허용을 물으면 허용합니다.

v0.1은 풀이·타이머·채점·백업을 제공합니다. **합격시대 결과 가져오기, 유형 분석, 직전 회차 대비**는 v0.2에서 추가할 예정입니다.
