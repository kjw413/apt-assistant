# APT Assistant — DCAT · LG Way Fit 인적성 연습·기록·분석 툴

e-book 교재나 온라인 모의고사 옆에 띄워 두고, **실전과 같은 영역별 시간 제한** 아래에서 풀이하면서 계산기·메모장·그림판을 쓰는 개인용 연습 툴입니다. 푼 기록은 자동으로 쌓이고, **시험별·영역별·유형별로 무엇을 먼저 공부하고 실전에서 어떻게 풀지** 분석해 줍니다.

- 서버·계정 없이 이 PC에서만 동작합니다(인터넷 연결 불필요).
- 기록은 Chrome 안에 저장되고, 세션이 끝날 때마다 백업 파일이 자동으로 내려받아집니다.

---

## 1. 설치할 것

| 항목 | 필수 여부 | 용도 |
|---|---|---|
| Windows 10/11 + **Google Chrome** | 필수 | 툴 실행(주소창 없는 앱 창으로 열림) |
| **ShareX** (https://getsharex.com) | 선택 | e-book 문항 캡처 → 문항별 풀이 시간·문제 이미지 기록 |
| Node.js 24 + npm | 개발·업데이트할 때만 | 소스를 고쳐 다시 빌드할 때 |

툴 자체는 `app/index.html` 파일 하나라서 따로 설치할 것이 없습니다.

## 2. 처음 한 번만 하는 설정

### 2-1. 바로가기 만들기

PowerShell에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/make-shortcut.ps1
```

바탕화면에 **'APT Assistant'** 아이콘이 생깁니다. 이 아이콘은 전용 Chrome 프로필(`%LOCALAPPDATA%\APT-Assistant\chrome-profile`)로 툴을 엽니다. 평소 쓰는 Chrome의 방문 기록을 지워도 툴 기록은 지워지지 않습니다.

### 2-2. 창 배치

1. e-book(또는 모의고사 사이트)을 띄웁니다.
2. 툴 창을 클릭하고 **Win + →** 로 화면 오른쪽에 붙입니다.
3. 두 창 사이 경계를 끌어 **e-book 70 : 툴 30** 정도로 맞춥니다.
4. 툴 폭이 560px 이상이면 왼쪽에 답안(OMR), 오른쪽에 도구(메모장·그림판·계산기)가 나란히 보입니다.

### 2-3. ShareX 설정 (문항 캡처를 쓸 때)

1. **파일 이름 형식:** 작업 설정 → 파일 이름에서 캡처 이름 형식을 `%pn_%y-%mo-%d_%h-%mi-%s`로 바꿉니다. '활성화된 창 촬영' 형식과 기본 형식 둘 다 바꿔 두는 것이 안전합니다. 툴은 파일 이름의 `연-월-일_시-분-초`로 캡처 시각을 읽습니다.
2. **캡처 후 작업:** '파일로 저장'만 켜고 **'이미지 업로드'는 반드시 끕니다.** 교재 화면이 인터넷에 올라가지 않게 하기 위해서입니다. '캡처 후 창 표시'도 끄면 풀이 흐름이 끊기지 않습니다.
3. **단축키:** ShareX 기본값 기준으로 `Alt + Print Screen`은 활성 창 캡처, `Print Screen`은 영역 캡처입니다. 기본값은 ShareX 버전에 따라 다를 수 있으니 '단축키 설정'에서 확인하세요. e-book 창만 찍는 '활성 창 캡처'를 권장합니다.
4. **툴과 연결:** 툴의 **설정 → 캡처 폴더 → 폴더 지정**에서 ShareX 저장 폴더(기본: `문서\ShareX\Screenshots` 아래 월별 폴더)를 고릅니다. Chrome이 폴더 읽기 권한을 물으면 허용합니다.

> 알라딘 e-book은 ShareX로 캡처되는 것을 확인했습니다.

## 3. 기능 구성

### 시험 프로필 (교재 시험 구성표 기준, 모두 5지선다)

| 시험 | 영역 · 문항 수 · 제한 시간 | 도구 |
|---|---|---|
| **두산 DCAT** (75문항 / 65분) | 언어논리 20·20분 → 언어표현 15·10분 → 수리자료분석 20·20분 → 공간추리 10·7분30초 → 도형추리 10·7분30초 | 공간추리·도형추리는 계산기·메모장·그림판 **사용 불가(잠금)** |
| **LG Way Fit Test** (80문항 / 80분) | 언어이해 → 언어추리 → 자료해석 → 창의수리, 각 20문항·20분 | 모두 사용 가능 |

- 영역별 시간, 영역 사이 쉬는 시간(기본 15초), 실전 자동 시작, 영역별 도구 허용은 **시작 화면 '조정'** 또는 **설정 → 시험별 시간·도구 설정**에서 바꿀 수 있습니다. '교재 기본값으로'를 누르면 원래대로 돌아갑니다.
- 끝난 영역으로 돌아가기 불가, 오답 감점 없음은 확인되지 않은 규칙이라 기본값으로 둔 것입니다.

### 응시 방식

| 범위 | 설명 |
|---|---|
| 전체 모의고사 | 프로필의 모든 영역을 순서대로 |
| 영역 하나만 | 한 영역만 그 영역 시간으로 |
| 자유 드릴 | 원하는 문항 수만큼. 시간은 '문항 수 × 영역 기준 시간'으로 자동 계산(직접 수정 가능) |
| 외부 모의고사(타이머·도구만) | 합격시대 같은 사이트 모의고사를 풀 때. 답은 사이트에서 고르고 툴은 영역 타이머와 도구만 제공 |

| 모드 | 시간이 다 되면 | 일시정지 |
|---|---|---|
| **실전** | 그 영역이 잠기고 쉬는 시간 뒤 다음 영역이 자동 시작 | 없음 |
| **연습** | 빨간 초과 시간이 표시되며 계속 풀 수 있음. 결과에 '제한 시간 안 점수'와 '전체 점수'가 따로 나옴 | 있음 |

### 풀이 화면

- **답안(OMR):** 문항 번호 옆 ①~⑤를 마우스로 누릅니다. 고른 답을 다시 누르면 선택이 해제됩니다. 다음에 풀 문항이 강조되고, 문항별 시간은 답을 누른 간격으로 자동 기록됩니다.
- **계산기:** 키보드 숫자·연산자·Enter·Backspace·Esc를 받습니다. 메모장에 입력 중일 때는 키가 메모로 가고, 메모 밖을 누르거나 Esc를 누르면 다시 계산기로 갑니다. **키보드로는 답이 찍히지 않습니다.**
- **메모장·그림판:** 탭으로 전환하고, 그림판은 검정·빨강 펜, 지우개, 전체 지우기, 실행 취소를 지원합니다.
- **알림:** 영역 마감 60초 전·마감·자동 시작 때 비프와 화면 깜빡임(설정에서 끌 수 있음).
- 창을 닫거나 새로고침해도 진행 중인 세션과 남은 시간이 그대로 이어집니다.

### 채점과 결과

- 세션이 끝나면 **정답 숫자열**(예: `31425…`)을 붙여넣거나 입력합니다. ③·２ 같은 원문자·전각 숫자도 읽고, `0`이나 `-`는 '정답 모름'으로 처리합니다.
- 결과 화면: 제한 시간 안 점수·전체 점수, 영역별 정답과 걸린 시간, 문항별 표(열 이름을 눌러 정렬).
- 정답은 문제집에 저장되어 같은 문제집을 다시 풀면 자동 채점되고, **'정답 수정'**으로 고치면 지난 기록도 함께 바뀝니다.

### 외부 모의고사(합격시대) 기록

- 합격시대 **1회** 결과(유형별 분석표 42행)는 사진을 판독해 처음 실행할 때 자동으로 들어가 있습니다.
- **2회부터:** 외부 모의고사 모드로 풀고 끝낸 뒤 **'채점 입력'**에서 채점표의 **내 답**과 **정답** 숫자열을 넣습니다. 문항 단위 기록이 됩니다.

### 유형 분류

- 결과 화면 아래 **'유형 칠하기'**에서 유형(예: 전개도, 자료해석)을 고르고 문항을 누르거나 끌어서 칠합니다.
- DCAT 전체 모의는 합격시대 1회의 문항 순서로 만든 **기본 틀**이 미리 칠해져 있어, 다른 곳만 고치면 됩니다. 고친 배치는 **'기본 틀로 저장'**으로 다음 회차에 씁니다.
- DCAT 유형 13개: 명제추리, 단문독해, 글의구조, 어휘어법, 어휘추리, 수열, 응용수리, 자료해석, 수/문자추리, 입체도형, 전개도, 평면도형, 도형추리. **'새 유형'**으로 추가할 수 있습니다.

### ShareX 캡처 연결

- e-book에서 **각 문항을 처음 펼칠 때 한 번** 캡처합니다.
- 세션이 끝나면 결과 화면 **'캡처 연결'** → 미리보기 확인 → **'연결 저장'**을 누릅니다. 캡처 장수가 문항 수와 다르면 영역별 '한 칸 밀기/당기기'로 맞춥니다.
- 연결된 문항은 **캡처 사이 간격**으로 풀이 시간이 계산되고, 문항 표의 **'보기'**로 문제 이미지를 다시 볼 수 있습니다. 이미지는 툴에 복사하지 않고 ShareX 폴더의 파일을 그대로 읽습니다.

### 누적 분석 (홈 → 분석)

- **지금 할 일:** 먼저 공부할 유형(예상 실점 순), 속도를 올릴 유형, 실전에서 나중에 풀 유형, 시간이 없으면 찍을 유형
- **회차별 기록:** 점수, 제한 시간 안 점수, 소요 시간, 영역별 정답 막대
- **영역별 성적:** 정답, 문항당 시간(기준 시간 대비), 미응답, 시간 부족으로 놓친 점수
- **유형별 성적:** 맞힘, 보정 정답률, 예상 실점(행을 누르면 세부 유형·푼 문항·출제 비중)
- **유형 지도:** 풀이 속도 × 정답률 산점도
- 계산 원리
  - 정답률은 기록을 모두 합쳐 계산합니다.
  - 문항이 적은 유형은 영역 평균 쪽으로 보정합니다(보정 강도 4문항).
  - 예상 실점 = 실전 출제 비중 × 실전 문항 수 × (1 − 보정 정답률)
  - 같은 문제집을 다시 푼 기록은 기본적으로 뺍니다('처음 푼 기록만').

## 4. 이렇게 쓰세요

**e-book 교재로 풀 때**
1. 홈 → **새 세션** → 시험·범위·모드·문제집 이름을 고르고 **시작**
2. 쉬는 시간 화면에서 e-book을 해당 쪽으로 넘김 → 시작(실전은 자동 시작)
3. 문항마다 (ShareX 캡처) → 풀이 → OMR에 답 클릭
4. 종료 → 정답 숫자열 입력 → **채점 저장**(백업 파일 자동 저장)
5. 결과 화면에서 유형 칠하기 확인, (캡처 연결)

**합격시대 모의고사를 풀 때**
1. 새 세션 → 범위 **외부 모의고사** → 이름 입력(예: 합격시대 DCAT 2회) → 시작
2. 사이트에서 풀면서 툴의 영역 타이머·도구 사용
3. 끝나면 **채점 입력**에서 채점표의 내 답·정답 입력 → 유형 칠하기 확인

## 5. 기록과 백업

- 기록 위치: `%LOCALAPPDATA%\APT-Assistant\chrome-profile` — **이 폴더를 지우면 기록도 사라집니다.**
- 세션을 채점·종료할 때마다 `apt-backup-날짜-시각.json`이 '다운로드' 폴더에 저장됩니다. 처음에 Chrome이 '여러 파일 다운로드'를 물으면 허용하세요.
- 복원: **설정 → 백업 파일 복원**(진행 중인 세션이 없을 때만 가능, 복원 직전 현재 기록을 먼저 내려받음)

## 6. 업데이트와 되돌리기 (개발용)

```powershell
npm install          # 처음 한 번
npm test             # 단위 테스트
npm run e2e          # 빌드 + 실제 Chrome 테스트
npm run release      # 테스트 통과 시 app/index.html 갱신(직전 판은 app/prev/)
```

되돌리기: `app/prev/index.html`을 `app/index.html`로 복사합니다.

## 7. 알아 둘 점

- 실제 DCAT/LG 시험 화면의 도구 크기·조작 방식은 공식 자료로 확인하지 못했습니다. 도구 배치는 SKCT 연습 툴을 참고했습니다.
- 끝난 영역 복귀, 오답 감점, 영역 사이 쉬는 시간 길이는 미확인 규칙입니다. 확인되면 '조정'에서 값만 바꾸면 됩니다.
- 설계 문서: `docs/superpowers/specs/2026-10-08-apt-assistant-design.md`
